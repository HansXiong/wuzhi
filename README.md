# 物值

一个轻量、离线优先的个人资产管理 PWA。

“物值”用于记录个人物品的购买价格、购买日期和使用分类，并通过持有时间计算每天使用这些物品的大致成本，帮助你了解自己的物品资产和使用效率。

当前版本：**v1.6.5**

## 主要功能

### 资产管理

- 添加、编辑和删除资产
- 记录资产名称、购买价格、购买日期、分类和备注
- 自动生成资产序号
- 支持按名称搜索和按分类筛选
- 支持按日均成本、购买日期、价格或名称排序
- 手机端使用紧凑卡片布局，减少屏幕空间占用

### 数据统计

- 总资产：所有资产购买价格之和
- 资产数量
- 平均持有时间
- 全部资产日均成本
- 按分类统计资产金额
- 最值得的物品排行
- 日均使用成本最高排行

### 分类管理

默认提供以下分类：

- 数码产品
- 生活运动
- 衣物鞋包
- 家具电器
- 交通出行
- 其他

所有分类都可以：

- 新增
- 删除
- 上移或下移排序

删除仍有资产的分类时，应用会先提示，并将这些资产转移到其他分类，避免资产丢失。

### 数据导入与备份

- CSV 导入资产
- CSV 导出资产
- JSON 完整备份
- JSON 备份恢复资产、分类和设置
- 清空全部资产，同时保留分类和设置
- 导入时校验名称、价格、日期和分类等必要字段

### 显示设置

- 日均成本显示 1 至 3 位小数
- 浅色主题
- 深色主题
- 跟随系统主题
- 设置进入资产页面时的默认排序方式

### PWA 与离线使用

- 可安装到电脑或安卓手机桌面
- 安装后以独立窗口运行
- Service Worker 缓存应用资源
- 首次加载完成后支持离线打开
- 无需账号和后端服务器

## 成本计算方式

物值使用购买价格和持有天数计算使用成本：

```text
持有天数 = max(今天 - 购买日期, 1)
单件资产日均成本 = 购买价格 ÷ 持有天数
全部资产日均成本 = 所有资产单件日均成本之和
```

例如，一件购买价格为 `365 元`、已经持有 `365 天` 的物品，日均成本约为：

```text
365 ÷ 365 = 1 元/天
```

金额统一使用人民币 `¥`。

## 使用方法

### 使用 GitHub Pages

1. 将项目部署到 GitHub Pages。
2. 使用 GitHub Pages 生成的 HTTPS 地址打开项目。
3. 在支持 PWA 的浏览器中选择“安装应用”或“添加到主屏幕”。

不要直接双击 `index.html` 使用。`file://` 地址无法正常使用 Service Worker 和 PWA 安装功能。

### 本地测试

如果电脑安装了 Python，可以在项目根目录运行：

```powershell
python -m http.server 8080
```

然后访问：

```text
http://localhost:8080
```

## 数据与隐私

- 资产数据保存在当前浏览器、当前网站的 IndexedDB 中。
- 数据不会自动上传到项目服务器。
- 当前版本没有账号系统、云端同步和多人协作功能。
- 不同浏览器、不同设备之间不会自动共享资产数据。
- 清除浏览器的网站数据可能会删除本地资产，因此建议定期导出 JSON 完整备份。
- 将来如果打包成 APK，APK 版本通常会使用独立的本地存储，迁移数据时可使用 JSON 备份恢复。

## 项目结构

```text
物值/
├─ index.html                 # 应用页面、样式和主要逻辑
├─ manifest.webmanifest       # PWA 应用清单
├─ sw.js                      # Service Worker 离线缓存
├─ icons/                     # 应用图标
└─ README.md                  # 项目说明
```

项目采用原生 HTML、CSS 和 JavaScript 实现，没有前端框架和运行时依赖。

## 安卓 APK

当前仓库首先作为 PWA 使用。如果需要 APK，可以使用 Capacitor 将现有网页封装成 Android 应用，不需要重写业务逻辑。

基本流程：

```powershell
npm init -y
npm install @capacitor/core @capacitor/android
npm install -D @capacitor/cli
npx cap init
npx cap add android
npx cap sync
npx cap open android
```

初始化时将网页资源目录设置为 `www`，并将 `index.html`、`manifest.webmanifest`、`sw.js` 和 `icons/` 复制到该目录。之后使用 Android Studio 测试或生成 APK。

详细说明参见 [Capacitor 官方文档](https://capacitorjs.com/docs/getting-started) 和 [Capacitor Android 文档](https://capacitorjs.com/docs/android)。

## 项目定位

物值刻意保持简单：先把个人资产记录、成本计算、分类管理和本地备份做好，再考虑云同步、账号系统、图片上传等需要额外服务的功能。
